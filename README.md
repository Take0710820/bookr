# 読書のすゝめ 〜本好きのための本紹介サイト〜

おすすめの本を紹介・共有するWebアプリケーションです。
ログインしてお気に入りの本を投稿したり、他のユーザーが紹介した本の中からランダムで「次に読む本」を見つけたりすることができます。

## 開発の背景

「次に何を読もう」と迷ったときに、ランキングや広告ではなく、本好きの人が本当に薦めたい一冊に出会える場所を作りたいと考えて開発しました。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| ユーザー登録・ログイン | ユーザー名とパスワードでアカウントを作成し、セッションでログイン状態を管理します |
| 本の紹介投稿 | 本のタイトル・紹介文・表紙画像をマイリストに登録できます |
| マイリスト | 自分が紹介した本の一覧と登録件数を表示します |
| 投稿の削除 | 投稿番号とパスワードを入力して、自分の投稿を削除できます |
| ランダムおすすめ | トップページで、全ユーザーの投稿からランダムに1冊を表示します |

## ファイル構成

```
src/
├── index.php      # トップページ（ランダムおすすめ表示）
├── login.php      # ユーザー登録・ログイン
├── recommend.php  # マイリスト（投稿・一覧・削除）
├── delite.php     # 開発用：テーブル初期化スクリプト
└── images/        # アップロードされた本の画像
```
